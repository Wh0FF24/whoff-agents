## #1 RECOMMENDED: Dev Tools / MCP Server Store (Score: 8.15)

### Why This Wins

**Market timing is perfect.** 17,000+ MCP servers exist but <5% are monetized. 350,000 Claude Code skills published in 5 months. Multiple analysts compare this to the 2008-2009 App Store moment. The window is open NOW and will narrow as major SaaS companies build official MCP servers within 12 months.

**Autonomy is near-perfect.** Claude can:
- Build MCP servers and Claude Code skills end-to-end
- Deploy hosted services (GitHub → Amplify pipeline exists)
- Write documentation, demos, marketing copy
- Iterate based on user feedback and analytics
- Publish to MCP directories (Glama.ai, mcpmarket.com)
- Manage Lemon Squeezy storefront

**Will's 5% involvement:**
- Stripe/Lemon Squeezy account setup (one-time)
- Approve any paid service integrations
- Occasional strategic direction

### Revenue Model
- **Freemium hosted MCP servers**: Free tier with usage cap → $15-30/mo pro tier
- **Premium skill bundles**: $29-$99 one-time (via Lemon Squeezy, 5% fee)
- **Flagship products**: $99-$299 one-time (boilerplate/starter kits)

### Revenue Projection
| Scenario | MRR by Month 12 |
|---|---|
| Conservative | $2,000-$5,000 |
| Realistic | $5,000-$12,000 |
| Aggressive | $12,000-$20,000 |

### Marketing Playbook
1. **Build in public on X/Twitter** — Post build process, ship announcements, demos. This is the #1 channel for dev tools. Claude can draft all content; Will approves/posts (or we automate posting).
2. **MCP directories** — List on Glama.ai, mcpmarket.com, claudemarketplaces.com. 21st.dev hit $10K MRR with zero marketing, purely from directory discovery.
3. **SEO content** — Blog posts on whoffagents.com targeting "MCP server for [use case]" long-tail keywords. Near-zero competition right now.
4. **GitHub presence** — Open-source core versions of tools to build trust. Premium features behind paywall.
5. **Product Hunt** — One-time launch spike + SEO backlink.

### What to Build First
Target specific professional workflows where the output is decision-ready:
- **Crypto/trading MCP servers** (leverage Will's domain expertise + existing bot work)
- **Data analysis/visualization tools** (high demand, Claude excels here)
- **Workflow automation skills** (the "ShipFast for Claude Code" angle)
- **Integration MCP servers** (connect popular services that don't have servers yet)

### Risks
- Ecosystem standards may shift (mitigated by Linux Foundation governance)
- 82% of MCP servers have security vulnerabilities → security-first approach is a differentiator
- Selling downloadable files gives away IP → prefer hosted/service model

## #2 STRONG COMPLEMENT: Newsletter (Score: 7.10)

### Why This Is #2

**Near-perfect autonomy** and **near-zero costs** ($25-75/month to run). The AI+crypto intersection is underserved. This works as a standalone business OR as a marketing funnel for the dev tools store.

**The synergy play:** A free newsletter about AI agents, MCP servers, and crypto automation drives traffic to whoffagents.com where the paid tools live. The newsletter becomes both a revenue stream (ads + paid tier) AND a customer acquisition channel.

### Revenue Model
- **Free tier**: Daily/weekly digest on AI agents + crypto (ad-supported)
- **Paid tier**: $15/month — premium analysis, trading signals, tool recommendations
- **Sponsorships**: $20-70 CPM in crypto/AI niche

### Revenue Projection
| Scenario | MRR by Month 12 |
|---|---|
| Conservative | $1,500-$3,000 |
| Realistic | $3,000-$8,000 |
| Aggressive | $8,000-$15,000 |

### Marketing Playbook
1. **Beehiiv platform** — No revenue share on paid subs, built-in Boosts network for cross-promotion ($2-3/subscriber)
2. **X/Twitter** — Cross-promote with dev tools content
3. **Referral program** — ~$0.17/subscriber, newsletters grow 35% faster with referrals
4. **Reddit communities** — r/cryptocurrency, r/artificial, r/algotrading

### What Makes It Defensible
Pure AI content is a commodity. The moat is **proprietary data**: on-chain analytics, trading bot performance data (from Will's Polymarket bot), MCP server benchmarks. Readers can't replicate this with ChatGPT.

### Risks
- Subscriber fatigue from AI-generated content flood
- Crypto ad budgets are cyclical (bull = flush, bear = dry)
- 5-20% free-to-paid conversion requires strong voice

## #3 DEPRIORITIZED: Agent Marketplace (Score: 6.55)

### Why It Drops

The general marketplace model is a proven graveyard (GPT Store pays $0.03/conversation). The successful version — vertical-specific agents sold direct — overlaps heavily with the Dev Tools recommendation but with more complexity and support burden.

**Better as a future expansion** of the dev tools store than a starting point. Once whoffagents.com has traffic and trust, adding pre-built agents as a product category is natural.

---

## #4 ELIMINATED: AI Consulting (Score: 5.65)

### Why It Fails the Autonomy Test

Despite the strongest raw revenue potential ($80K-$250K year 1), consulting fundamentally breaks the 95% autonomy constraint:
- Clients want to talk to a human before signing $5K+ retainers
- Sales calls, contract negotiations, and client escalations require Will
- Liability for AI-generated deliverables needs legal structure
- Realistic automation ceiling is 80-90%, not 95%

**The math doesn't work for the goal.** This is a "Will works 10-20 hours/week" business, not a "Claude runs it" business.
